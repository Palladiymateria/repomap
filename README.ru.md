# RepoMap

### Весь нужный контекст проекта — в одном файле.

**Командная строка · Python 3.10+ · Без сторонних библиотек для запуска · MIT**

Показывает дерево проекта и собирает выбранные текстовые файлы в Markdown для передачи ИИ. Работает локально: аккаунт и API-ключ не нужны, ничего автоматически не отправляется.

## Запуск

Установи Python 3.10+ и Git, затем скачай проект:

```sh
git clone https://github.com/Palladiymateria/repomap.git
cd repomap
```

Проверить Git: `git --version`. Если он не установлен, скачай его с [git-scm.com](https://git-scm.com/downloads). Можно также выбрать **Code → Download ZIP** на GitHub и открыть терминал в распакованной папке.

Запусти из папки RepoMap, где находится `pyproject.toml`:

```powershell
python -m repomap .
python -m repomap "C:\path\to\project" --bundle -o context.md
```

Первая команда показывает дерево. Вторая создаёт документ с деревом и содержимым файлов. На macOS и Linux вместо `python` может понадобиться `python3`.

Для короткой команды и запуска из любой папки:

```sh
python -m pip install .
repomap --help
repomap .
```

Установка может скачать инструменты сборки. Само сканирование работает без сетевых запросов. Без установки выполняй `python -m repomap` из папки исходников RepoMap.

## Команды

| Задача | Команда |
| --- | --- |
| Дерево проекта | `repomap .` |
| Показать два уровня дерева | `repomap . --depth 2` |
| Собрать только Python | `repomap . --bundle --include "*.py" -o context.md` |
| Выбрать Python и Markdown | `repomap . --bundle --include "*.py" --include "*.md"` |
| Исключить тесты | `repomap . --exclude tests` |
| Общий лимит 256 КиБ | `repomap . --bundle --max-total-kb 256` |
| Лимит одного файла 32 КиБ | `repomap . --bundle --max-file-kb 32` |
| Сохранить дерево | `repomap . -o tree.txt` |

Шаблоны заключай в кавычки. Они учитывают регистр и сравниваются с относительным путём или именем файла по правилам Python `fnmatch`; `*` может совпадать с `/`. Исключения важнее включений. `--depth` ограничивает только отображение дерева, но не набор файлов в документе. Пустые папки не отображаются.

## Как использовать с ИИ

1. Выбери нужные файлы с помощью `--include` и `--exclude`.
2. Создай `context.md` и проверь, нет ли внутри секретов и приватных данных.
3. Прикрепи документ к своему вопросу в выбранном ИИ-сервисе.

Файлы внутри документа — данные проекта, а не доверенные инструкции для ИИ.

## Исключения и ограничения

- Пропускаются `.git`, `.venv`, `venv`, `node_modules`, `__pycache__`, `.pytest_cache`, `dist`, `build`, `.next`.
- Исключены `.env`, все `.env.*`, некоторые имена файлов учётных данных и файлы `.pem`, `.key`, `.p12`, `.pfx`.
- Символические ссылки не обходятся. Junction-папки исключаются, если версия Python поддерживает их определение.
- При проверке корня Git-репозитория учитываются игнорируемые Git неотслеживаемые файлы. Уже отслеживаемые файлы остаются доступными. Нужен установленный Git; в подпапках эта фильтрация не применяется. Статус выводится в терминале.
- В документ не попадают двоичные файлы с NUL-байтами, текст не в UTF-8, недоступные файлы и содержимое сверх лимитов. Причины перечисляются в конце документа.

По умолчанию: **128 КиБ на файл**, **1 МиБ исходного содержимого**, **5 уровней дерева**. Это байты, не токены ИИ и не размер итогового Markdown. Встроенные исключения имён и папок не отображаются в дереве.

Это не сканер секретов: ключи могут находиться в обычном исходном коде. Проверь документ перед отправкой. Сканируй доверенные папки, которые не меняются во время работы. Существующий выходной файл не перезаписывается; выбранный путь результата исключается из текущей проверки. Другие старые документы автоматически не исключаются.

## Результат

Дерево или Markdown выводятся в stdout, либо сохраняются через `--output` в UTF-8. Сводка идёт в stderr. Код `0` означает завершение, в том числе с пропущенными файлами; `2` — ошибку аргументов или операции. Проверяй список пропущенных файлов.

## Тесты

```sh
python -m unittest discover -s tests -v
```

Идеи для развития: оценка токенов, дополнительные источники исключений и граф зависимостей. Пока не реализованы.
